# G-коды для Delta X 1

## G00, G01 — Линейное перемещение

### Описание

Команды **G0** и **G1** добавляют в очередь **ЛИНЕЙНОЕ ПЕРЕМЕЩЕНИЕ**, которое будет выполнено после завершения всех предыдущих перемещений. Команда вида **G1 F1000** устанавливает скорость подачи для всех последующих перемещений.

### Использование

```gcode
G00 [F<скорость>] [X<позиция>] [Y<позиция>] [Z<позиция>] [W<угол>]
G01 [F<скорость>] [X<позиция>] [Y<позиция>] [Z<позиция>] [W<угол>]
```

### Параметры

* `F[скорость]` — (мм/с) максимальная скорость перемещения между начальной и конечной точкой. Установленное значение применяется ко всем последующим перемещениям, если параметр не указан.
* `X[позиция]` — (мм) координата по оси X.
* `Y[позиция]` — (мм) координата по оси Y.
* `Z[позиция]` — (мм) координата по оси Z.
* `W[угол]` — координата по 4-й оси.

### Пример

```gcode
G01 X12                         ; переместиться на 12 мм по оси X
G01 F200                        ; установить скорость 200 мм/с
G01 X90.6 Y13.8                 ; переместиться в X=90.6 мм, Y=13.8 мм
G01 X0 Y0 Z-350
G01 W90                         ; повернуть 4-ю ось на 90°
G01 X100 Y50 Z-400 W90 U45 F200 ; X=100 мм, Y=50 мм, Z=-400 мм, W=90°, U=45°, F=200 мм/с
```

## G02, G03 — Движение по дуге или окружности

### Описание

**G2** добавляет движение по дуге **по часовой стрелке**, а **G3** — **против часовой стрелки**. Дуга начинается в текущем положении и заканчивается в указанной точке XYZ. Центр дуги задаётся смещениями I и J.

### Использование

```gcode
G2 [F<скорость>] [I<смещение>] [J<смещение>] [X<позиция>] [Y<позиция>] [W<угол>]
G3 [F<скорость>] [I<смещение>] [J<смещение>] [X<позиция>] [Y<позиция>] [W<угол>]
```

### Параметры

* `F[скорость]` — (мм/с) максимальная скорость перемещения.
* `I[смещение]` — (мм) смещение от текущей позиции X до центра дуги.
* `J[смещение]` — (мм) смещение от текущей позиции Y до центра дуги.
* `X[позиция]` — (мм) координата по оси X.
* `Y[позиция]` — (мм) координата по оси Y.
* `W[угол]` — координата по 4-й оси.

### Пример

```gcode
G28
G01 Z-350
G01 X50
G02 X-50 Y0 I-50 J0
G03 X50 Y0 I50 J0
```

## G04 — Пауза (задержка)

### Описание

Команда приостанавливает выполнение очереди команд на заданное время.

### Использование

```gcode
G04 [P<время>]
```

### Параметры

* `P[время]` — время задержки в миллисекундах.

### Пример

```gcode
G01 X0 Y0 Z-350
G04 P500          ; задержка 500 мс
G01 X100
```

## G05 — Кубическая кривая Безье

### Описание

**G5** создаёт кубическую B-сплайн-кривую в плоскости XY. Параметры **P** и **Q** обязательны. Для первой команды G5 в серии также обязательны **I** и **J**.

### Использование

```gcode
G5 [F<скорость>] I<позиция> J<позиция> P<позиция> Q<позиция> X<позиция> Y<позиция>
```

### Параметры

* `F[скорость]` — (мм/с) максимальная скорость перемещения.
* `I[смещение]` — (мм) смещение от начальной точки по X до первой контрольной точки.
* `J[смещение]` — (мм) смещение от начальной точки по Y до первой контрольной точки.
* `P[смещение]` — (мм) смещение от конечной точки по X до второй контрольной точки.
* `Q[смещение]` — (мм) смещение от конечной точки по Y до второй контрольной точки.
* `X[позиция]` — конечная координата X.
* `Y[позиция]` — конечная координата Y.

### Пример

```gcode
; нарисовать плавную форму буквы N
G0 X0 Y0
G5 I0 J3 P0 Q-3 X1 Y1
```

## G06 — Управление углами Theta

### Описание

Позволяет напрямую задавать углы приводов без указания конечных координат.

### Использование

```gcode
G06 [X<угол>] [Y<угол>] [Z<угол>] [P<позиция>]
```

### Параметры

* `X[угол]` — (градусы) угол Theta 1.
* `Y[угол]` — (градусы) угол Theta 2.
* `Z[угол]` — (градусы) угол Theta 3.
* `P[позиция]` — (мм) пройденное расстояние.

### Пример

```gcode
G06 X0 Y0 Z0      ; установить углы Theta 1, Theta 2 и Theta 3 в 0°
```

## G93 — Получение текущей позиции

#### Описание

Команда **G93** используется для получения текущего положения рабочего органа (End Effector) робота в декартовой системе координат.

#### Использование

```gcode
G93
```

#### Ответ контроллера

```text
<xpos>,<ypos>,<zpos>
```

#### Параметры ответа

* `<xpos>` — текущая координата по оси X (мм).
* `<ypos>` — текущая координата по оси Y (мм).
* `<zpos>` — текущая координата по оси Z (мм).

#### Пример

```gcode
G93              ; получить текущую позицию
```

Ответ:

```text
31,43,-291
```

Расшифровка ответа:

* X = 31 мм
* Y = 43 мм
* Z = -291 мм

Это означает, что рабочий орган находится в точке **(31; 43; -291)** относительно текущей системы координат.

## M03, M04 — Включение выхода / Лазера / Вакуума / Закрытие захвата

### Описание

Команда **M03** используется для включения вакуумного насоса, лазера или закрытия захвата.

### Использование

```gcode
M03 [S<значение>]
```

### Параметры

* `S[значение]`

  * вакуумный насос;
  * скорость шпинделя (0–255);
  * мощность лазера (0–255);
  * угол захвата (0–100);
  * если значение не указано — захват закрывается.

**Примечание:** `M03` эквивалентна `M03 S255`.

### Пример

```gcode
G01 X0 Y0 Z-350
M03                   ; включить вакуумный насос
G01 Z-300
```

## M360 — Выбор рабочего инструмента (End Effector)

### Описание

Позволяет выбрать установленный инструмент робота.

### Использование

```gcode
M360 E<значение>
```

### Параметры

* `E=0` — вакуумный захват (по умолчанию)
* `E=1` — механический захват
* `E=2` — ручка/маркер
* `E=3` — лазер
* `E=4` — 3D-принтер
* `E=5` — пользовательский инструмент

### Пример

```gcode
M360 E2 ; выбрать инструмент «Ручка»
```
